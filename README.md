# 🧵 Threads | The Next-Generation Social Experience

> **A full-stack, high-performance clone of Meta's Threads.** Built with the powerhouse combination of Next.js 14, MongoDB, and Clerk to deliver a seamless, real-time social networking experience.

---

## ✨ Features that Pop

* **⚡ Server-Side Power:** Lightning-fast page loads and SEO optimization using **Next.js 14 App Router**.
* **🧩 Nested Conversations:** Multi-level threading for deep, organized discussions.
* **👥 Community Hubs:** Create and manage groups with unique permissions and member management.
* **👤 Pro Profiles:** Fully customizable bios, activity history, and follower tracking.
* **🔍 Instant Discovery:** Global search functionality for users and communities alike.
* **🔔 Live Activity:** Real-time updates for likes, replies, and community invites.

---

| Tool | Purpose |

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Atchaya-Lakshman/threads_app.git
cd threads_app
```

### 2. Set up Environment Variables

Create a .env.local file in the root directory and add your keys:
```bash
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_key
CLERK_SECRET_KEY=your_secret
MONGODB_URL=your_mongodb_url
UPLOADTHING_SECRET=your_secret
UPLOADTHING_APP_ID=your_id
```

### 3. Ignite the App
```bash
npm install
npm run dev
```
